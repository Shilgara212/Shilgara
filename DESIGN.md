# Shilgara visual direction

**Idea:** a quiet academic studio. The orbit mark represents several parts of student life finding one center: courses, grades, exams, and a four-year journey. It is drawn as native vector geometry in the interface and app icon.

**Palette:** deep navy for focus, warm paper for breathing room in light mode, violet for actions, muted teal for progress, and a restrained amber focal point. Dark mode uses ink surfaces with brighter text accents. Decorative color never represents a confirmed grade.

**Layout:** an anchored sidebar; generous editorial typography; a single strong hero; compact cards for actionable information. Empty states explain the next useful action without inventing academic records. With data present, the same visual system yields to course results and schedules.

**Interaction:** primary actions are visible at the moment they become useful. All academic values stay editable. Motions are short and tied to navigation or state changes. The interface remains in English, while development discussion can remain in Chinese.
